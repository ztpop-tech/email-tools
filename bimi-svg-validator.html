BIMI SVG 校验器

免费在线工具 · Logo 合规检查（AuthIndicators BIMI）· 浏览器端运行，不上传数据

BIMI（Brand Indicators for Message Identification）在认证邮件旁显示品牌 Logo，但 SVG 文件必须符合规范（AuthIndicators BIMI）：纯 SVG、无脚本、无外部引用、含 viewBox、宽高比接近 1:1。本工具粘贴 SVG 代码或上传文件，逐项检查合规性并输出可执行的修复建议。

检查项：格式/根元素、viewBox、宽高比、脚本、外部引用、栅格图像、动画、颜色数量、尺寸。全部在浏览器本地完成。

BIMI SVG 合规要求

要求规范依据
纯 SVG 格式（不可 PNG/JPG）AuthIndicators BIMI §Logo Requirements
必须包含 viewBox 且宽高比 ≈ 1:1AuthIndicators BIMI §Logo Requirements
无 <script>、无事件处理（on* 属性）SVG Tiny 1.2 子集，防脚本注入
无外部引用（<image> href、@import、外部 CSS）防跟踪与资源注入
无动画（<animate>/<animateTransform>）BIMI 要求静态 Logo
无栅格图像（<image>/<foreignObject>）必须为矢量图形
建议最小 512×512 像素邮箱服务商渲染要求（如 Gmail 至少 512px）
颜色数量有限（VMC 认证 Logo 需单色/特定色板）VMC 证书签发要求

规范来源：AuthIndicators BIMI（BIMI Group 公开规范，SVG 部分基于 W3C SVG Tiny 1.2）。

使用方法

① 将品牌 Logo 导出为 SVG（矢量工具导出，勿用位图转格式）；② 粘贴代码或上传文件；③ 点击「校验 SVG」查看合规清单。全部通过后，将文件托管到 HTTPS 域名（需带正确 Content-Type: image/svg+xml），并在 DNS 发布 default._bimi.域名 TXT 记录（如 v=BIMI1; l=https://cdn.example.com/logo.svg;），同时确保 DMARC 为 p=quarantine 或 p=reject。

技术标准依据

本工具基于以下公开规范实现：

  • AuthIndicators BIMI（Brand Indicators for Message Identification，BIMI Group 规范，v0.7 草案）
  • W3C SVG Tiny 1.2（Scalable Vector Graphics 子集规范）
  • RFC 7489（DMARC，BIMI 前置要求）
